📅 팀 공유 캘린더 team_schedule

화면에서 보는 team_schedule
팀 일정 도우미

버튼을 누르는 웹사이트가 아니에요. 명령어 한 줄로 실행하거나 매일 자동으로 돌아가면서, 팀의 구글 공유 캘린더를 정리해 Slack으로 알려주는 도구예요. 이 페이지는 그 결과가 실제로 어떻게 생겼는지 보여주는 미리보기입니다.

이건 어떻게 생긴 도구인가요?

클릭하는 화면이 따로 있는 게 아니라, 터미널에서 python -m team_schedule ... 명령으로 실행하거나 매일 정해진 시각에 자동(cron / GitHub Actions)으로 돌아갑니다. 그 “결과”는 두 곳에 나타나요.

🖥️ 터미널(콘솔) 화면 💬 Slack 알림 메시지
한눈에 보기

네 가지 일을 합니다

각 기능은 명령어 하나에 대응돼요. 새 일정을 알려주고, 일정을 요약하고, 반복 일정을 만들고, 겹치는 일정을 찾아줍니다.

1🆕

새 일정 알림

notify-new

공유 캘린더에 새로 생긴 일정만 골라 Slack으로 알림을 보냅니다.

2📋

일정 요약

summary --daily / --weekly

오늘 또는 이번 주의 일정을 보기 좋게 정리해서 보여줍니다.

3🔁

반복 일정 등록

add-recurring

매주 반복되는 일정(예: 스탠드업)을 캘린더에 자동으로 만들어 줍니다.

4⚠️

중복/겹침 확인

check-conflicts

시간이 겹치거나 똑같이 중복된 일정을 찾아 알려줍니다.

터미널 화면

콘솔에 뜨는 요약 박스

명령어를 입력하면 터미널에 이렇게 테두리 박스로 그려진 요약이 나타납니다. 아래는 “일간 요약”을 실행한 모습이에요.

team_schedule — 터미널
$ python -m team_schedule summary --daily
┌───────────────────────────────────┐
│ 📅 2026-01-05 (월) 일정            │
│ 09:00–09:15  데일리 스탠드업  · 2명 │
│ 10:00–11:00  디자인 리뷰           │
└───────────────────────────────────┘
✓ 일간 요약을 전송했습니다

한글과 이모지는 글자 폭이 넓어서 테두리가 완벽히 맞아떨어지진 않아요. 실제 도구는 글자 폭을 계산해(width-aware) 최대한 가지런하게 그립니다.

Slack 알림

Slack에 도착하는 메시지

같은 내용이 팀 Slack 채널에도 메시지로 올라옵니다. “Team Schedule”이라는 앱(봇)이 보내는 것처럼 보여요. 네 가지 기능이 각각 어떤 메시지를 보내는지 볼게요.

1 새 일정 알림 notify-new
🆕
Team Schedule앱오전 9:02
🆕 디자인 리뷰🕒 2026-01-05 10:00–11:00📍 회의실 A👥 a@example.com, b@example.com (2명)🔗 캘린더 링크

새로 추가된 일정 1건마다 이런 메시지가 하나씩 올라옵니다.

2 일정 요약 · 일간 summary --daily
📅
Team Schedule앱오전 8:00
📅 2026-01-05 (월) 일정09:00–09:15 데일리 스탠드업 · 2명10:00–11:00 디자인 리뷰
2 일정 요약 · 주간 summary --weekly
🗓️
Team Schedule앱월요일 오전 8:00
🗓 2026-01-05 주간 일정 01-05 (월) 09:00–09:15 데일리 스탠드업 · 2명01-06 (화) 일정 없음01-07 (수) 09:00–09:15 데일리 스탠드업 · 2명01-08 (목) 14:00–15:00 고객 미팅

한 주를 요일별로 나눠서 보여줍니다. (예시는 4일치만 보여줬어요.)

3 반복 일정 등록 add-recurring

이 기능은 Slack 메시지를 보내지 않아요. 대신 캘린더에 반복 일정을 직접 만들고, 터미널에 결과를 보여줍니다.

team_schedule — 터미널
$ python -m team_schedule add-recurring \
    --summary "데일리 스탠드업" \
    --start 2026-01-05T09:00:00+09:00 \
    --end   2026-01-05T09:15:00+09:00 \
    --freq WEEKLY --byday MO,WE,FR --count 10
✓ 반복 일정을 생성했습니다: evt_8f3a21c9
# 구글 캘린더에 RRULE 규칙을 직접 넣습니다
FREQ=WEEKLY;BYDAY=MO,WE,FR;COUNT=10
🔁 매주 월·수·금 09:00 반복 · 총 10회
4 중복/겹침 확인 check-conflicts
⚠️
Team Schedule앱오전 8:05
⚠️ 겹치는 일정• 디자인 리뷰 (2026-01-05 10:00–11:00) ↔ 1:1 미팅 (2026-01-05 10:30–11:00)
♻️
Team Schedule앱오전 8:05
♻️ 중복 일정• 주간회의, 주간회의 (2건)

시간이 겹치는 일정(↔)과 똑같이 중복 등록된 일정(♻️)을 각각 찾아 알려줍니다.

실행 방법 · 설정

어떻게 돌아가나요?

명령어를 직접 입력해서 실행하거나, 매일 정해진 시각에 자동으로 돌게 해둘 수 있어요. 실제 캘린더와 연결하려면 아래 3가지 준비물이 필요합니다.

연결에 필요한 3가지 준비물 보기 ›
1구글 서비스 계정 JSON 키 + Calendar API 사용 설정 — 도구가 캘린더를 읽기 위한 열쇠예요.
2공유 캘린더에 서비스 계정 이메일 공유 — 그 열쇠에게 캘린더 보기 권한을 줍니다.
3Slack Incoming Webhook URL — 알림을 보낼 Slack 채널 주소예요.
환경 변수
GOOGLE_CALENDAR_ID = 공유 캘린더 ID
GOOGLE_SERVICE_ACCOUNT_FILE = 서비스 계정 JSON 경로
SLACK_WEBHOOK_URL = Slack 수신 웹훅 주소
TEAM_SCHEDULE_TZ = Asia/Seoul

자세한 설정 방법은 저장소의 README에 정리돼 있어요.

💡 이 페이지에 보이는 일정(디자인 리뷰, 데일리 스탠드업 등)은 모두 설명용 예시 데이터예요. 여러분의 실제 캘린더가 아닙니다. 준비물을 연결하면 그때부터 도구가 실제 구글 캘린더의 내용을 그대로 읽어옵니다.
